# Nanopore sequencing beyond the DNA sequence — habilitation talk

Code behind the habilitation talk of Martin Hölzer, Freie Universität Berlin, 2 December 2026:
**"Nanopore sequencing beyond the DNA sequence: Computational challenges and opportunities
for bacterial genomics"**.

All own figures and simulations in the talk are generated by the scripts in this repository.
The slide deck itself is also assembled by a script from a hand-made PowerPoint template.

## What you can reproduce

| Output | Script | Inputs |
|---|---|---|
| Consensus error rate → expected false cgMLST allele differences; majority-vote consensus | `scripts/sim_cgmlst_errors.py` | none |
| cgMLST explainer (core genes → alleles → allele distances → tree) | `scripts/fig_cgmlst_scheme.py` | none |
| Schematics: per-read modification calls → motif; separating lineages by methylation; Gram matrix as a position-free representation (toy data) | `scripts/fig_schematics.py` | none |
| Slide deck | `scripts/build_deck.py` | private (see below) |

Generated figures are in `figures/generated/`.

### The cgMLST error model in one line
For a scheme with `N` loci of length `L` and a per-base consensus error rate `ε`, the expected
number of false allele differences between two genomes of the same strain is

`E[D] = N · (1 − (1 − ε)^(2L))`

With `N = 2,513` (EnteroBase *E. coli* cgMLST) and `L ≈ 1 kb`, staying below the EHEC cluster
threshold of 10 alleles requires a consensus accuracy of about Q57 (≈ 5 errors per 2.5 Mb).
The script checks the formula with a Monte-Carlo simulation.

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/sim_cgmlst_errors.py
.venv/bin/python scripts/fig_cgmlst_scheme.py
.venv/bin/python scripts/fig_schematics.py
```

## Building the deck (needs private inputs)

The deck build combines the hand-made template with figures from published papers, slides of
co-authors and unpublished manuscripts. These inputs are not part of this repository.
The pipeline is documented for transparency:

```bash
.venv/bin/python scripts/extract_media.py        # pictures from source decks
bash scripts/extract_paper_figs.sh               # figures from paper PDFs
bash scripts/render_pptx.sh <deck.pptx> <outdir> 250   # macOS + Keynote: pptx → PDF → PNG
.venv/bin/python scripts/crops.py                # crop figure regions from renders
.venv/bin/python scripts/zooms.py                # zoom-ins on dense paper figures
.venv/bin/python scripts/build_deck.py           # → build/2026-FU-Habil-Hoelzer-Talk_vXX.pptx
```

Figures from other work are cited on each slide.
